# ZEB-ROI 홍보영상 기획안 (1분 30초 / 90초)

레퍼런스(땡쓰·센클라우드·스윙챗)의 공식을 따르되, 강조색은 **파인그린**,
"제품 화면"은 **우리 실제 Streamlit 앱 스크린샷**을 쓴다.
**정직성**: 화면에 지어낸 수치(NPV 몇 억 등)를 띄우지 않는다. 검증된 사실만.

## 스타일 가이드
- **색**: 아이보리 바탕 `#FBFAF8` · 먹 `#16211D` · 강조 파인그린 `#175E4C` · 전환용 그린 블록 `#0F4A3B`
- **폰트**: 볼드 산세리프 헤드라인(Pretendard/에스코어드림 계열) + **숫자·라벨은 모노**(Cascadia/D2Coding)
- **모션**: 컬러블록 와이프 전환 · 텍스트 한 줄씩 리빌 · 스크린샷은 브라우저 프레임에 떠서 슬라이드-인 · 큰 숫자는 카운트업/슬라이더
- **페이싱**: 차분·전문적. 컷당 3~5초. 급하지 않게.
- **음악**: 잔잔하게 시작 → 기능 투어에서 상승 → CTA에서 여운. 나레이션(성우) 한국어.
- **비율**: 1920×1080 (16:9). 자막 항상 병기(무음 시청 대비).

## 내레이션 전체 (성우 대본, ~90초 분량)
1. 오래된 건물을 고치기 전, 세 가지가 막막합니다.
2. 감이 아니라, 근거로. ZEB-ROI.
3. BIM 한 번으로 ZEB·에너지효율등급을 평가하고, 비용·보조금·회수기간까지 한 자리에서.
4. 도면 하나로 등급·정량평가·비용·회수를 한 번에. 실제 EnergyPlus 해석까지.
5. 법·고시 원문을 조항째 인용합니다. 원문에 없으면 지어내지 않고 '자료에 없다'고 답합니다.
6. 문장 한 줄로 보조금과 회수기간을 가늠합니다. 숫자는 엔진이 계산하고, AI는 조건만 읽습니다.
7. 공공과 민간을 나눠, 대화로 신청서 초안까지 만듭니다.
8. 왜 믿을 수 있나 — 모든 숫자는 엔진이 계산하고, 근거 조항까지 되짚을 수 있습니다.
9. 실제 공공건물로 전 과정을 검증했습니다.
10. 지금, 당신의 건물로 확인해 보세요.

## 필요한 실제 화면 스크린샷 (씬 4~7a)
- ZEB 등급 탭: ZEB 5등급 배너 + GR 점수
- 정책 Q&A: 답변 + 출처 인용 박스
- ROI 시뮬레이션: 보조금·회수기간이 보이는 답변
- 사업 신청 인테이크: 공공/민간 트랙 라디오 + 신청서 초안 미리보기
> 캡처는 zeb-bim-tool.streamlit.app에서 직접, 또는 로컬에서. (원하면 내가 캡처해 드림)

## 정직성 체크 (화면에 띄우면 안 되는 것)
- 확정 NPV/회수 '몇 억·몇 년' 수치를 사실처럼 — 넣으려면 "예:" 표기.
- "국내 유일/최초/최고" · 탄소 감축량(우리 기능 아님).
- "도담이 EnergyPlus를 돌렸다" — 도담은 JSON, E+는 별도 gbXML 데모(씬4의 E+는 데모 화면으로).
- "ZEB에 도달하려고 그린리모델링" 인과.
- 안전한 고정 사실: ZEB 5등급 · 11개 기술요소 · 1,251㎡ · 2014 · 보조금 50/70% · EnergyPlus 25.1.

## 이 기획안으로 실제 영상 만드는 법 (택1)
1. **모션그래픽 편집자에게** 이 표를 그대로 전달 (After Effects). 레퍼런스 3개 + 이 기획안이면 바로 착수 가능.
2. **AI 영상툴**(예: 컷·자막·나레이션 자동): 씬별 자막+VO 대본을 넣고 우리 스크린샷을 소스로.
3. **템플릿 툴**(Canva/CapCut 모션 템플릿): 위 타임라인대로 텍스트·스크린샷 교체.
공통: 나레이션은 위 '성우 대본' 사용, 강조색은 파인그린, 숫자는 모노폰트.
